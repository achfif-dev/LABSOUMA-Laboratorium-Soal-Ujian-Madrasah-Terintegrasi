# Audit aplikasi dan fitur Bank Soal Manual (16 Nov 2026)

## Ringkasan audit
Aplikasi dalam kondisi baik: React + Vite di depan, satu gateway Vercel (`api/gateway.js`) untuk semua rute, Firebase Auth + Firestore, autentikasi per rute, kuota/rate limit, aturan Firestore ketat.
Baseline sebelum perubahan: 931 tes lulus; 13 berkas tes gagal HANYA karena paket (`react`, `docx`, `lucide-react`, `write-excel-file`) tidak terpasang di lingkungan audit tanpa jaringan. Bukan cacat kode; jalankan `npm ci && npm test` untuk memastikan di mesin Anda.

Terverifikasi aman:
- Dua `dangerouslySetInnerHTML` (Compose.jsx, PegonTab.jsx) hanya menerima HTML yang dibangun `pegon.js` dengan `escapeHtml`.
- Gateway menolak rute tidak dikenal dan nama bawaan Object; tiap rute memanggil autentikasi sendiri; ada tes struktur untuk ini.
- Masukan AI selalu dibersihkan (`cleanLine` membuang `<` `>`), diberi pembatas data, dan keluarannya divalidasi kode.

Temuan / saran (belum diubah, di luar permintaan):
1. **Backup Drive hanya mencakup koleksi `soal`** (`src/backup.js`). Koleksi baru `soalLuar` BELUM ikut tercadangkan. Naskah manual tidak bisa disusun ulang dari AI, jadi sebaiknya masuk cadangan (saran: tahap berikutnya).
2. Semua staf (termasuk penyusun) dapat membaca kunci semua soal, termasuk bank manual. Ini konsisten dengan aturan lama; hanya perlu diketahui.
3. Naskah .docx asli tidak disimpan (tidak ada Firebase Storage di paket gratis); yang disimpan teks butir, nama, ukuran, dan SHA-256 berkas.
4. Tidak ada tes UI otomatis untuk `BankLuar.jsx` yang dapat dijalankan tanpa paket React; komponen baru diperiksa sintaksnya (esbuild) tetapi BELUM dirender di browser.

## Fitur baru
- **Tab "Bank Soal Manual (Word)"** (grup Bank Soal): unggah .docx format Dauri (+ naskah kunci opsional), pratinjau yang dapat disunting, pernyataan verifikasi luar, kisi-kisi, daftar bank, unduh kisi-kisi DOCX/CSV, ubah kisi-kisi, hapus.
- **Parser** `web/lib/soalDocx.js`: tanpa dependensi, mengenali judul Dauri, bagian أ/ب/ج, opsi, kunci merah, jawaban merah, halaman `ص`, kutipan `نص الكتاب`, kop (mapel/kelas), nomor otomatis Word; menolak berkas jahat (batas ukuran, zip bomb).
- **Kisi-kisi**: AI (rute `soal-luar`, aksi `kisi`; hasil divalidasi kode, indikator berawalan baku, bab dari daftar bila diberikan) atau draf lokal tanpa AI. Selalu ditandai (`ai` / `draf` / `manual`) dan dihitung "perlu ditinjau".
- **Bank khusus**: koleksi `soalLuar`, hanya server yang menulis (aturan Firestore `write: if false`). Menyimpan/hapus: editor & admin; ubah kisi: pencatat atau admin. Naskah identik ditolak (hash isi).
- Keputusan desain: sengaja TIDAK dimasukkan ke koleksi `soal` agar tidak memalsukan jejak persetujuan (gerbang kutipan, uji buta, tahap editor).

Tes baru: `test/soalDocx.test.js` (15), `test/soalLuar.test.js` (23). Tes navigasi disesuaikan (15→16 tab).
